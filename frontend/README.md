# Frontend - Website Files

This folder contains all the website files that users see and interact with.

## Files Explained

### HTML Files (Website Pages)
- `index.html` - Login page
- `student-menu.html` - Student main menu
- `student-session.html` - View and register for sessions
- `student-details.html` - Student profile page
- `student-feedback.html` - Give feedback page
- `admin.html` - Admin dashboard
- `counselor.html` - Counselor dashboard

### JavaScript File
- `script.js` - Makes the website interactive (handles clicks, forms, etc.)

### CSS Folder
- Contains all styling files that make the website look good

### Assets Folder
- Contains images and icons used on the website

## How It Works

1. **Login**: Users select their role and enter username/password
2. **Navigation**: Users can click buttons to go to different pages
3. **Forms**: Users can fill out forms (feedback, registration, etc.)
4. **API Calls**: JavaScript sends data to the backend server

## Key JavaScript Functions

- `handleLoginForm()` - Processes login
- `loadSessions()` - Gets sessions from server
- `handleFeedbackForm()` - Submits feedback
- `showMessage()` - Shows popup messages

## No Need to Change

The CSS files are already styled and work well. Focus on understanding the JavaScript if you want to add features.
